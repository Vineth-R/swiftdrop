# Inserting M1 report content

The report is maintained as a Word document
(`SwiftDrop_with_M5_Section3.docx`). The M1 deliverables are provided as
Markdown and editable diagram source so the existing document is not modified
programmatically.

## Sections

1. Open `SwiftDrop_with_M5_Section3.docx` in Word.
2. Insert `section_4_1_architecture.md` immediately after the `4.1 Architecture`
   heading.
3. Insert `section_4_4_deployment.md` immediately after the `4.4 Deployment`
   heading.
4. Keep the existing styles: Heading 1 for `4.1`/`4.4`, Heading 2 for
   subsections, and the existing table style for tables.
5. Check that the section references to Figure 7 point to the inserted figure.

## Figure 7

1. Open `../diagrams/figure-7-platform-architecture.drawio` in
   diagrams.net (app.diagrams.net or the desktop app).
2. Export as PNG at 200–300% scale, or as SVG for print.
3. Insert the image after the `4.1 Architecture` prose with the caption:
   “Figure 7 — SwiftDrop platform architecture.”
4. Keep the `.drawio` file committed as the editable source.

## Review notes

`m2-section-2.6-and-7-review.md` is a review note for Sections 2.6 and 7. It is
not report content; use it to complete those sections with the owning author.
